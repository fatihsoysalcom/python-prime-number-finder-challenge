# Python Prime Number Finder Challenge

This Python script demonstrates a common type of programming challenge: finding prime numbers up to a given limit. It illustrates basic algorithmic thinking, function decomposition, and iterative problem-solving, reflecting the spirit of a "DEV Challenge" as described in the article. The example is self-contained and uses only standard Python features.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt in the same directory.
3. Run the script using: `python main.py`
